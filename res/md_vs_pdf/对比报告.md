# PDF 与 MD 作为 RAG 知识源的对比评测报告

> 生成时间：2026-08-19 20:06:09

## 1. 实验概述

- **评测框架**：ragas 0.4.3（`evaluate` + Faithfulness / AnswerRelevancy / ContextPrecision / ContextRecall）
- **LLM**：deepseek-v4-flash
- **Embedding**：BAAI/bge-large-zh-v1.5（1024 维）
- **向量库**：Milvus，库 `vehicle`，集合 `pdf_collection`（原始 PDF）与 `md_collection`（MinerU 转换 MD）
- **分块**：chunk_size=512，overlap=100；**检索**：similarity_search，top_k=5
- **测试集**：117 个问答对，覆盖 16 个新能源汽车标准文档（GB/GBT/QCT）

## 4. 结论

基于上表均值对比：

- **忠实度 Faithfulness**：MD 劣于 PDF（0.9303 vs 0.8886，差值 -0.0417）
- **答案相关性 Answer Relevancy**：MD 优于 PDF（0.6799 vs 0.6964，差值 +0.0165）
- **上下文精确率 Context Precision**：MD 优于 PDF（0.5077 vs 0.5078，差值 +0.0002）
- **上下文召回率 Context Recall**：MD 优于 PDF（0.7009 vs 0.7179，差值 +0.0171）

### 解读

- **检索能力（召回/精确）**：MD 在上下文召回率上小幅领先（+0.017），上下文精确率基本持平，说明 MinerU 处理过的表格、图片转文字等信息，让检索命中正确答案略好；但两者都未拉开显著差距。
- **生成质量（忠实度/相关性）**：PDF 的忠实度明显更高（-0.042），MD 的答案相关性略高（+0.017）。可能原因：PDF 抽取的文本更“原汁原味”，模型倾向直接引用原文，因此更忠实；MD 文本更通顺，模型回答更流畅、相关性更好，但也更容易产生上下文未直接支持的表述。
- **总体**：MD 作为知识源在检索与答案相关性上略优于 PDF，但差距不大；若更看重答案忠实度，PDF 更稳。可在后续工作中尝试以 MD 为主、结合 PDF 原文纠偏的混合方案，或针对 MD 增加“仅依据上下文回答”的约束提示来提升忠实度。
